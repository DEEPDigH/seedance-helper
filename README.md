# Seedance 助手

用于即梦网页版的浏览器扩展，提供项目任务队列、参考素材管理、参数同步和逐模型并发监测。支持 Seedance 2.5 与 Seedance 2.0 系列，使用 Manifest V3。

当前版本：`5.0.46`。扩展管理页中仍使用原名称 `Seedance 2.0助手5.0.46_ANDREAM`。

## 主要功能

- **项目与任务队列**：按项目组织任务，支持任务编辑、重复次数、执行记录、失败重试和暂停。
- **参考素材**：管理图片、视频、音频及项目素材，通过提示词中的 `@` 引用素材。
- **参数同步**：向即梦页面同步模型、参考模式、比例、分辨率和时长。
- **并发监测**：按模型检测平台任务状态，根据普通组和 VIP 组限额安排队列。
- **批量导入导出**：使用 CSV 管理任务参数，或使用 ZIP 打包任务表格和素材。
- **提示词编辑**：提供放大编辑、提示词模板与素材引用展示。
- **辅助工具**：提供人脸分割和效率统计入口。

## 安装

本项目直接加载源码即可，无需安装 Node.js 或构建依赖。

1. 在仓库页面选择 **Code → Download ZIP**，并解压到固定目录；也可以使用下方命令克隆。
2. 在 Chrome 打开 `chrome://extensions/`，在 Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的项目目录。
5. 打开并登录[即梦](https://jimeng.jianying.com/)，进入视频生成页面，再点击扩展图标打开助手窗口。

```sh
git clone https://github.com/DEEPDigH/seedance-helper.git
```

更新源码后，在浏览器扩展管理页点击“重新加载”，再重新打开助手。更新 `net-hook.js` 后，还需要刷新即梦页面以重新注入脚本。

## 使用

1. 创建或选择项目。
2. 在底部输入区设置任务名称、重复次数、模型、参考模式和生成参数。
3. 添加素材并填写提示词，也可以通过项目素材面板预存素材。
4. 提交为任务卡片，检查参数和素材后执行队列。
5. 在并发监测区查看逐模型状态，并按需设置 VIP 组上限。

打开助手时的默认值：

| 参数 | 默认值 |
| --- | --- |
| 模型 | Seedance 2.5 |
| 参考模式 | 全能参考 |
| 比例 | 21:9 |
| 分辨率 | 480P |
| 生成数量 | 1 |
| 时长 | 5 秒 |

模型列表顺序为 `Seedance 2.5 → Seedance 2.0 mini → Seedance 2.0 Fast VIP → Seedance 2.0 VIP → Seedance 2.0 Fast → Seedance 2.0`。可选模型会随参考模式变化。

当前代码中，Seedance 2.5 支持 `480P / 720P`，普通生成时长为 `4–30 秒`，超长视频模式为 `30–180 秒`。实际可用能力取决于即梦页面和账号权限。

### CSV / ZIP

在“项目管理”中导入或导出当前项目。

- CSV 主要列包括创作模式、模型、参考模式、比例、时长、提示词。
- 提示词中的 `@素材名` 用于匹配素材；导入 CSV 时可选择素材根目录。
- ZIP 可以打包任务表格和素材，方便项目迁移。
- 建议以插件导出的表格作为模板，保留列名并使用 UTF-8 编码。

## 权限与数据

| 权限 | 用途 |
| --- | --- |
| `scripting` | 在即梦页面运行参数同步、素材提交和状态检测脚本 |
| `tabs` | 定位即梦标签页及打开、聚焦助手窗口 |
| `storage` | 在浏览器本地保存项目、任务、模板和监测设置 |
| `alarms` | 调度后台并发检测及队列续跑 |
| 即梦站点访问权限 | 仅声明 `jimeng.jianying.com` 及其子域名 |

`net-hook.js` 在即梦页面捕获相关任务历史接口的响应，用于识别平台生成状态。任务和设置保存在浏览器本地；上传参考素材和提交生成任务时会与即梦平台交互。

## 常见问题

- **找不到即梦生成页**：确认已登录即梦并进入视频生成页面，然后重新启动监测。
- **更新后仍显示旧界面**：重新加载扩展并关闭、重新打开助手窗口；必要时刷新即梦页面。
- **参数无法同步**：确认账号和当前模型支持该选项；即梦网页结构变化可能需要更新页面匹配逻辑。
- **迁移或重装**：提前导出项目 ZIP。浏览器本地数据不会随 Git 仓库同步。

本项目为第三方辅助工具，与即梦官方无隶属关系。执行生成任务仍使用用户自己的即梦账号、权限和积分。
